# 404号室には誰もいない
この事件には、被害者が一人多い。

架空都市・静浜を舞台とする全6章のARGです。

## 起動
Python 3（標準ライブラリのみ）でプロジェクトルートから実行：
```sh
python3 server.py
```
http://127.0.0.1:8040/ をブラウザーで開き、導入メールから開始。停止はCtrl+C。ポート変更は `python3 server.py --port 8041`。

**旧版の `python3 -m http.server` は使わないでください。** 正解判定・章解放には専用サーバーが必要です。ルートやprivate/を静的配信しないでください。

## 現行版の構成
- `web/`：第1章、共通案内、ブログ写真・CSS・JavaScript。
- `private/`：第2章以降の本文と証拠画像。正解した段階に応じてserver.pyが配信。
- `server.py`：正解判定、順序確認、HTTP配信。ディレクトリ一覧は配信しない。
- `.local/progress.sqlite3`：匿名のプレイ進捗。Git管理外。再起動後も継続できる。

ブラウザーには匿名セッションIDのHttpOnly Cookieを保存。ブラウザーの保存値を書き換えても章は解放されません。旧版のlocalStorage進捗は引き継がず、最初から開始します。リセットは「この作品について」から。Cookieが必要です。保存期間の目安は30日。

約45〜75分想定、未計測。全6章。実メール送信・外部サービスへの通信・現地調査は不要。写真3点は架空の町を描いたAI生成画像です。謎用の監視映像と音声は照合用文字記録、写真比較は模式図を使用しています。

Renderへの公開方法と無料プランの一時SQLite構成は [`DEPLOY.md`](DEPLOY.md) を参照してください。
